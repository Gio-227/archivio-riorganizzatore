# Semantica — dominio AMMINISTRATIVO (aree concettuali + procedimenti)

Classifica gli atti per **area concettuale** e **procedimento**, non per tipo file. Un atto fa
parte di un filo procedurale che ha un inizio e una fine.

## 1. Estrazione testo PDF

PDF con layer testo → estrai e analizza. PDF scansionato (senza testo) → badge **VERIFICA** con
nota standard: "Documento scansionato — contenuto non letto. Verificare manualmente prima di
archiviare." Nessuna supposizione dal solo nome file (un "fattura_2023.pdf" è *possibile*, non certo).

## 2. Classificazione per aree

Usa le aree definite dall'utente nel briefing. Non inventare aree senza chiedere. Per ogni
documento: area · procedimento di riferimento (se identificabile) · relazione con altri atti ·
stato (in corso / concluso / archiviato).

## 3. Relazioni tra atti

Pattern: stessa intestazione → stesso procedimento · riferimenti incrociati ("in risposta alla
vostra del…", "allegato a…") · numeri di protocollo/riferimento condivisi · date sequenziali su
argomenti correlati.

## 4. Output — Mappa procedimenti

PROCEDIMENTO · atti trovati N · cartella suggerita · stato (in corso / concluso / non
determinabile) · documenti correlati (avvio → risposta del [data] → delibera finale) · note
(mancanti, VERIFICA aperti).
